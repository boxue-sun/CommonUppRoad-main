## 一、为什么要用强化学习？

### 当前的做法（网格穷举）

你现在做实验是这样：把参数空间切成网格，每个格子跑一遍 UPPAAL 验证。

```
距离:    3, 5, 8, 10, 15, 20, 30, 50          (8个)
障碍物速度: 0, 1, 3, 5, 10                      (5个)
ego速度:  10, 15, 20, 25, 30                    (5个)
→ 总共 8×5×5 = 200 个变体，每个都要跑
```

**问题**：200 个还能跑，如果参数更多呢？比如加上切入角度、反应时间、路面摩擦……指数爆炸，穷举不了。

### RL 的想法

不要让机器盲目穷举，而是让机器**学会**"什么参数组合容易碰撞"，然后**优先搜索**那些区域。就像一个有经验的人，知道"距离近+速度快"容易出事，会先查那里。

## 二、什么是 Q-Learning？

### 2.1 核心概念

想象一个迷宫，每个格子有不同奖励：

```
[起点] → [ ] → [ ] → [+10金币!]
  ↓
[ ] → [-1陷阱] → [ ]
```

你每一步可以**上下左右**移动。Q-Learning 的目标是：学会每个格子里"往哪个方向走最划算"。

**Q 值**（Q-value）存的就是：在某个位置做某个动作，**从长远来看能拿多少分**。

### 2.2 更新公式

```
新Q值 = 旧Q值 + 学习率 × (即时奖励 + 折扣因子 × 下一步最佳Q值 - 旧Q值)
```

用人话：如果你往右走了一步得了 10 分，而且右边那个格子的最佳方向能再得 5 分，那"往右走"这个动作的估值就该上调。

### 2.3 探索 vs 利用

- **探索（Exploration）**：随机乱走，发现新区域。用 `epsilon` 控制概率。
- **利用（Exploitation）**：走已知的最优方向。用 `1-epsilon` 的概率。

训练初期 epsilon 高（多探索），后期 epsilon 低（多利用）。这跟你学骑车一样——开始乱试，后来肌肉记忆。

## 三、我们的 RL 系统设计

### 3.1 环境（Environment）

```
状态 = (距离索引, 障碍物速度索引, ego速度索引)
      = 3D 参数空间中的一个格子
```

每个格子存着：**这个参数组合下，ISO 15622 ACC 会不会撞**（来自之前 200 个变体的 CSV 数据）。

### 3.2 动作（Actions）

Agent 可以做 6 种动作：

```
动作 0: 距离 -1   → 把障碍物挪近 1 档
动作 1: 距离 +1   → 把障碍物挪远 1 档
动作 2: obs速度 -1
动作 3: obs速度 +1
动作 4: ego速度 -1
动作 5: ego速度 +1
```

### 3.3 奖励（Reward）

```
找到碰撞:     +10 分  ← 目标！
安全（没撞）:  -1 分  ← 浪费了一次查询
重复访问:     -0.5 分 ← 别老在一个地方打转
```

Agent 的目标：**用最少的步数，找到尽可能多的碰撞场景**。

### 3.4 训练过程

```
初始化：Q 值全为 0，epsilon=1.0（100% 随机探索）

Episode 1:
  Agent 从随机位置出发 → 乱走 60 步 → 路过的格子更新 Q 值
  有些步撞了(+10)，有些没撞(-1)

Episode 100:
  epsilon 降到了 0.6 → 40% 概率走最优方向
  Agent 发现了："低距离+高速度"的区域 Q 值特别高

Episode 500:
  epsilon 降到 0.08 → 92% 走最优方向
  Agent 完全学会了：直接往危险区冲
```

## 五、这给你的论文提供了什么？

### 论点

> 形式化验证（UPPAAL）穷举了**障碍物行为**空间，但没有穷举**场景参数**空间。RL 可以补上这个缺口：用 RL 智能搜索参数空间，找到最危险的场景参数组合，再交给 UPPAAL 做确定性验证。

### 实验可以这样写

```
Method:
  1. 定义参数空间 P = {距离, v_ego, v_obs, ...}
  2. Q-learning agent 在 P 中搜索
  3. 每步查询 UPPAAL 验证（或查已有的 ground truth 表）
  4. Agent 学会危险参数分布

Results:
  - RL 找到 100% 碰撞，查询次数减少 60 倍
  - Q 值热力图与真实碰撞分布高度吻合
  - 证明该方法可扩展到更大参数空间
```

### 下一步可以做

1. **在线 RL**：不查表，直接调 UPPAAL 验证，看 Agent 能否在真实环境中学习
2. **更大参数空间**：加入更多参数（反应时间、刹车强度、路面摩擦等）
3. **迁移学习**：在追尾场景训练的 Agent，迁移到切入场景
