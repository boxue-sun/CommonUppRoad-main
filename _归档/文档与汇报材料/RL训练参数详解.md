# 离线 RL 训练参数详解（老师会问的都在这里）

---

## 一、训练规模

| 参数 | 值 | 大白话 |
|------|-----|--------|
| **训练回合 (Episodes)** | **500 轮** | 500 次"从起点出发走到终点" |
| **每轮步数** | 最多 60 步（访问60个不同状态后结束） | 每轮 Agent 在参数空间中走 60 步 |
| **总步数** | 500 × 60 = 最多 30,000 步 | 但很多是重复的，实际约 ~15,000 次有效查询 |
| **状态空间** | 8×5×5 = **200 个状态** | 来自 close_range 实验的 200 个变体 |
| **Q 表大小** | 200 × 6 = **1,200 个条目** | 每个状态存 6 个动作的估值 |

---

## 二、超参数

| 参数 | 值 | 作用 | 为什么选这个值 |
|------|-----|------|-------------|
| **学习率 α** | **0.1** | 新经验覆盖旧经验的速度 | 0.1 中庸。太大(0.5)会震荡，太小(0.01)学得太慢 |
| **折扣因子 γ** | **0.95** | 对未来奖励的重视程度 | 0.95 偏重未来——Agent 愿意走几步去拿高分。γ=0 只看眼前 |
| **初始探索率 ε** | **1.0** | 一开始 100% 随机 | 完全不知道哪里危险，先乱走 |
| **最小探索率** | **0.05** | 最后至少保留 5% 随机 | 防止 Agent 永远不探索新区域 |
| **探索衰减** | **0.995/轮** | 每轮乘以 0.995 | 慢慢从探索过渡到利用 |

---

## 三、ε 怎么衰减的

```
Episode   1: ε = 1.000  -> 100% 随机乱走
Episode  50: ε = 0.778  -> 78% 随机，22% 走学过的最优方向
Episode 100: ε = 0.606  -> 大概一半一半
Episode 200: ε = 0.367  -> 37% 探索，63% 利用
Episode 300: ε = 0.222  -> 22% 探索
Episode 400: ε = 0.135  -> 主要在利用
Episode 500: ε = 0.082  -> 92% 走最优方向，8% 继续探索
```

**老师问"为什么不是线性衰减"：** 指数衰减在前期探索多、后期利用多，符合学习规律。前期需要大量探索建立 Q 表，后期需要利用学到的知识高效搜索。

---

## 四、奖励函数

| 情况 | 奖励值 | 设计理由 |
|------|--------|---------|
| 找到碰撞 | **+10** | 大正奖励，让 Agent 记住这条路 |
| 安全（没撞） | **-1** | 小惩罚，浪费了一次查询 |
| 重复访问 | **-0.5** | 比安全的惩罚轻，鼓励去"已知好区域附近"而不是打转 |

---

## 五、动作空间（6 种）

```
动作 0: 距离 -1   (把前车挪近一档)
动作 1: 距离 +1   (把前车挪远一档)
动作 2: obs速度 -1
动作 3: obs速度 +1
动作 4: ego速度 -1
动作 5: ego速度 +1
```

边界处理：如果已经是最小距离，再选"距离-1"就原地不动（不报错）。

---

## 六、训练结果

| 指标 | 值 |
|------|-----|
| 总碰撞场景 | 68/200 (34%) |
| Agent 找到 | 68/68 (100%) |
| 训练曲线 | 奖励从 ~100 涨到 ~400（收敛） |

## 七、老师可能追问的 & 怎么答

| 问题 | 回答 |
|------|------|
| "500 轮够不够？" | "够了，看训练曲线——200 轮后奖励就基本稳定在 400 左右，说明收敛了。再多训练也不会有明显提升。" |
| "200 个状态是不是太少了？" | "对，确实少。所以这只是离线验证——证明 RL 思路可行。下一步要扩展到更大的在线空间。" |
| "α=0.1 为什么？试过其他的吗？" | "0.1 是经验值。试过 0.5（震荡）和 0.01（太慢），0.1 最稳定。如果老师有兴趣我可以做参数敏感度分析。" |
| "γ=0.95 意味着什么？" | "Agent 愿意为未来的高分放弃眼前的低分。简单说：它愿意穿过几个安全区，去找到远处的碰撞区。" |
| "Q 表不会太大吗？" | "200×6=1200 条，完全在内存里。但如果状态空间变大（比如 10000 个状态），Q 表就太大了——这就是为什么下一步要用 DQN，用神经网络代替 Q 表。" |
| "为什么每轮 60 步？" | "200 个状态，60 步能覆盖 30%。太多步会在一轮里穷举完，太少步学不到东西。60 是个折中。" |
