## 一、研究背景（1分钟）

**目标**：用形式化验证方法，系统性地找到使自动驾驶算法碰撞的场景。

**方法**：UPPAAL 形式化验证 + ISO 15622 法规模型

**核心优势**：传统仿真只能测试少量场景，UPPAAL 能穷举所有可能的障碍物行为组合。

## 二、ISO 15622 ACC 模型（3分钟）

### 2.1 什么是 ISO 15622

ISO 15622 是国际标准化组织发布的《智能运输系统 自适应巡航控制(ACC)系统 性能要求与测试规程》，是全球最通用的跟车功能法规模准。

### 2.2 四模式决策逻辑

```
┌─────────────────────────────────────────────────┐
│  1. 自由流模式 (Free-flow)                       │
│     触发：前方无车或距离 > 80m                    │
│     行为：加速到设定巡航速度 30 m/s               │
├─────────────────────────────────────────────────┤
│  2. 接近模式 (Approach)                          │
│     触发：80m > 距离 > 跟车距离+5m               │
│     行为：线性减速，越近减得越多                   │
├─────────────────────────────────────────────────┤
│  3. 跟车模式 (Following)                         │
│     触发：跟车距离 > 距离 > 2m                    │
│     行为：保持 1.8s 时距，P 控制器调节             │
├─────────────────────────────────────────────────┤
│  4. 制动模式 (Braking)                           │
│     触发：TTC < 1.5s 或距离 < 2m                 │
│     行为：紧急制动 -6.0 m/s²                     │
└─────────────────────────────────────────────────┘
```

### 2.3 关键参数

| 参数 | 值 | 说明 |
|---|---|---|
| 巡航速度 | 30 m/s | 设定速度上限 |
| 时距 | 1.8s | 跟车保持的安全时间 |
| 最小间距 | 2.0m | 最近跟车距离 |
| 舒适减速度 | -2.0 m/s² | 正常跟车减速 |
| 紧急减速度 | -6.0 m/s² | 紧急制动 |
| 反应延迟 | 1.5s | 传感器+执行器延迟 |

## 三、实验结果（3分钟）

### 3.1 近距离追尾实验

- **场景**：同向同车道追尾（ego 在后，障碍物在前）
- **参数空间**：8 距离 × 5 障碍物速度 × 5 ego 速度 = 200 个变体
- **验证方法**：UPPAAL 穷举所有障碍物行为组合

**碰撞率对比**：

| 模型 | 碰撞 | 安全 | 碰撞率 |
|---|---|---|---|
| 旧 TTC 反应式 | 78 | 122 | **39.0%** |
| ISO 15622 四模式 | 68 | 132 | **34.0%** |

### 3.2 热力图分析

**距离 vs ego 速度**：

```
            ego=10  ego=15  ego=20  ego=25  ego=30
dist=3m     100%    100%    100%    100%    100%   ← 全碰撞
dist=5m      80%     80%    100%    100%    100%
dist=8m       0%      0%      0%     60%    100%
dist=10m      0%      0%      0%     80%     60%
dist=15m      0%      0%      0%     40%     60%
dist=20m+     0%      0%      0%      0%      0%  ← 全安全
```

**关键发现**：安全边界在 15-20m，20m 以上全部安全。

### 3.3 跟车急刹实验（重点）

**老师要求的场景**：前车突然刹车，后车没刹住追尾。

**实验设置**：
- ego 和 obs 以 30 m/s 同速行驶
- obs 在 t=3s 时突然急刹 -10 m/s²
- ego 有 1.5s 反应延迟 + 渐进刹车

**结果**：
- ego 在 t=4.8s 追尾
- 碰撞时 ego 速度 30 m/s（完全没来得及刹车）

## 四、遇到的问题（3分钟）

### 4.1 ISO 15622 模型太安全

**问题**：即使障碍物减速度 10 m/s²（比 ego 的 6.0 更大），UPPAAL 验证仍然找不到碰撞。

**原因分析**：
- ISO 15622 的 TTC 检测太灵敏（TTC < 3s 就触发）
- ego 的最大减速度（-6.0）大于障碍物的制动能力
- 渐进刹车虽然慢，但足够在碰撞前刹住

**结论**：ISO 15622 是一个非常安全的模型，近距离追尾场景下几乎不会碰撞。

### 4.2 UPPAAL 状态空间爆炸

**问题**：障碍物行为自动机每步有 3 种选择（刹车/匀速/加速），150 步 = 3^150 种路径。UPPAAL 在有限时间内无法穷举所有路径。

**解决**：用 Python 模拟一条具体碰撞轨迹，作为可视化展示。

### 4.3 碰撞检测机制

**问题**：UPPAAL 用圆形近似检测碰撞，圆形比矩形大，导致视觉上没撞但检测说撞了。

**解决**：减小碰撞阈值（THRESHOLD 从 4.0 改到 1.5），让碰撞检测更接近实际接触。
