# 汇报稿 — 近距离碰撞实验与结论

> 日期：2026年6月17日（与方老师线下讨论）

---

## 一、做了什么实验（2分钟）

### 实验目的

上次汇报发现：原始场景中障碍物太远，IDM 总能避开。这次我们设计了**近距离碰撞实验**，系统地测试 IDM 在不同距离和速度下的安全边界。

### 实验设计

把障碍物直接放在 ego 正前方，变化 3 个参数：

| 参数 | 取值 | 含义 |
|------|------|------|
| 距离 | 3, 5, 8, 10, 15, 20, 30, 50 米 | 障碍物在 ego 前方多远 |
| 障碍物速度 | 0, 1, 3, 5, 10 m/s | 障碍物从静止到慢速 |
| Ego 速度 | 10, 15, 20, 25, 30 m/s | 从 36 km/h 到 108 km/h |

**8 × 5 × 5 = 200 个变体**，每个生成一个 UPPAAL 模型，用 verifyta 批量验证。

### 验证查询

```
A[] !cps_i_state.detection.collide
```
- TRUE = 安全（IDM 成功刹车）
- FALSE = 碰撞（IDM 刹不住）

---

## 二、实验结果（2分钟）

```
200 个变体 → 78 个碰撞，122 个安全 → 碰撞率 39%
```

### 碰撞规律

| 距离 | Ego 速度 | 结果 |
|------|---------|------|
| 3-5 米 | 10-30 m/s（任何速度） | **大部分碰撞** |
| 8-10 米 | ≥25 m/s（≥90 km/h） | **碰撞** |
| 15-20 米 | ≥25 m/s | **碰撞** |
| 30-50 米 | ≥30 m/s（108 km/h） | **碰撞** |
| 任何距离 | ≤15 m/s（≤54 km/h） | **安全** |

---

## 三、结论（2分钟）

### 结论 1：IDM 有安全边界

IDM 不是万能的。当**距离太近 + 速度太高**时，即使 IDM 最大刹车（-10 m/s²），也刹不住。

- 低速（≤54 km/h）：IDM 在任何距离都能避开 → **安全**
- 高速（≥90 km/h）：距离小于 20 米就刹不住 → **碰撞**

### 结论 2：距离和速度共同决定碰撞

碰撞不是单一参数决定的，而是**距离 × 速度的组合**：

```
距离近 + 速度低 → 安全（刹得住）
距离近 + 速度高 → 碰撞（刹不住）
距离远 + 速度高 → 安全（有足够反应时间）
```

### 结论 3：形式化验证的价值

通过 UPPAAL 穷举障碍物行为（9 种组合）+ Python 穷举初始条件（200 个变体），我们**系统地找到了 IDM 控制器的安全临界点**。这是传统仿真难以做到的。
