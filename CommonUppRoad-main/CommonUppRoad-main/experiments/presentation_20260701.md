## 二、ISO 15622 ACC 模型（3分钟）

### 2.1 什么是 ISO 15622

ISO 15622 是国际标准化组织发布的《智能运输系统 自适应巡航控制(ACC)系统 性能要求与测试规程》，是全球最通用的跟车功能法规模准。

### 2.2 四模式决策逻辑

```
┌─────────────────────────────────────────────────┐
│  1. 自由流模式 (Free-flow)                       │
│     触发：前方无车或距离 > 80m                    │
│     行为：加速到设定巡航速度 30 m/s               │
├─────────────────────────────────────────────────┤
│  2. 接近模式 (Approach)                          │
│     触发：80m > 距离 > 跟车距离+5m               │
│     行为：线性减速，越近减得越多                   │
├─────────────────────────────────────────────────┤
│  3. 跟车模式 (Following)                         │
│     触发：跟车距离 > 距离 > 2m                    │
│     行为：保持 1.8s 时距，P 控制器调节             │
├─────────────────────────────────────────────────┤
│  4. 制动模式 (Braking)                           │
│     触发：TTC < 1.5s 或距离 < 2m                 │
│     行为：紧急制动 -6.0 m/s²                     │
└─────────────────────────────────────────────────┘
```

### 2.3 关键参数

| 参数 | 值 | 说明 |
|---|---|---|
| 巡航速度 | 30 m/s | 设定速度上限 |
| 时距 | 1.8s | 跟车保持的安全时间 |
| 最小间距 | 2.0m | 最近跟车距离 |
| 舒适减速度 | -2.0 m/s² | 正常跟车减速 |
| 紧急减速度 | -6.0 m/s² | 紧急制动 |
| 反应延迟 | 1.5s | 传感器+执行器延迟 |

### 2.4 与旧模型的对比

| | 旧 TTC 反应式 | ISO 15622 四模式 |
|---|---|---|
| 巡航速度 | 无上限，无限加速 | 30 m/s 上限 |
| 跟车模式 | 不存在 | 保持 1.8s 时距 |
| 模式切换 | 安全/危险二值跳变 | 平滑过渡 |
| 合规性 | 无标准依据 | ISO 国际标准 |

## 三、实验结果（3分钟）

### 3.1 实验设置

- **场景**：同向同车道追尾（ego 在后，障碍物在前）
- **参数空间**：8 距离 × 5 障碍物速度 × 5 ego 速度 = 200 个变体
- **验证方法**：UPPAAL 穷举所有障碍物行为组合

### 3.2 碰撞率对比

| 模型 | 碰撞 | 安全 | 碰撞率 |
|---|---|---|---|
| 旧 TTC 反应式 | 78 | 122 | **39.0%** |
| ISO 15622 四模式 | 68 | 132 | **34.0%** |

**ISO 15622 比旧模型减少 10 个碰撞场景（-5%）。**

### 3.3 热力图分析

**左图：距离 vs ego 速度**

```
            ego=10  ego=15  ego=20  ego=25  ego=30
dist=3m     100%    100%    100%    100%    100%   ← 全碰撞
dist=5m      80%     80%    100%    100%    100%   ← 近距离高碰撞
dist=8m       0%      0%      0%     60%    100%   ← 高速才碰撞
dist=10m      0%      0%      0%     80%     60%
dist=15m      0%      0%      0%     40%     60%
dist=20m      0%      0%      0%      0%      0%   ← 全安全
dist=30m      0%      0%      0%      0%      0%
dist=50m      0%      0%      0%      0%      0%
```

**关键发现**：
- 3-5m 近距离：几乎全部碰撞（反应延迟内已冲过）
- 8-15m 中距离：仅 ego ≥ 25 m/s 碰撞
- 20m+ 远距离：全部安全

**右图：障碍物速度 vs ego 速度**

- 障碍物速度越低，碰撞率越高（相对速度大）
- ego 速度越高，碰撞率越高
